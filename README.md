# SillyTavern Cardplayer

这是一个面向 SillyTavern 角色卡的真实游玩与验收 Skill，基于 SillyTavern 1.17.0 设计。它不是只读取卡片文本做静态判断，而是让 AI 进入实际聊天环境，像玩家一样连续游玩，并观察角色回复、聊天记录、可见界面和状态变化。

Cardplayer 将“为了好玩”和“为了找问题”明确分开。娱乐模式下，AI 只根据角色卡标题、用户目标、所选玩家类型以及游玩中实际看到的信息行动；用户可以单纯旁观，看它如何选择、推进剧情，最后获得一份玩家视角的经历与感受报告。它不会因为普通剧情不合口味就停下来诊断，也不会为了追求完美反复重刷。

测试模式则保留技术观察层。AI 会模拟目标受众自然游玩，同时核对正文、变量更新、持久化结果和 HUD 是否一致；需要精确排查时，还可以使用确定性行动复现 MVU、状态结算或世界书问题。玩家所知道的内容与技术审计证据彼此隔离，避免隐藏信息影响真实的游玩选择。

涉及导入和复测时，Skill 会使用独立测试卡、世界书和聊天，尽量保护生产卡与既有会话。它也会区分角色卡更新与世界书更新，防止宿主缓存、旧角色对象或错误导入顺序造成版本串线。测试结束后只保留约定需要的证据与最新测试聊天，减少长期使用留下的杂乱内容。

## 模式

| 模式 | 用途 |
| --- | --- |
| `entertainment-play` | AI 专心代入游玩，用户旁观，结束后输出玩家视角的体验报告。 |
| `human-playtest` | 模拟目标受众自然游玩，同时记录技术与体验问题。 |
| `variable-repair` | 确定性检查 MVU、变量、状态、持久化和 HUD。 |
| `full-gate` | 先完成变量修复验收，再进行真人式游玩测试。 |

## 安装

让 Codex 从本仓库安装，或手动执行：

```powershell
git clone https://github.com/BW1145/sillytavern-cardplayer.git "$HOME/.codex/skills/sillytavern-cardplayer"
```

## 使用

在任务中调用 `$sillytavern-cardplayer`，指定模式、角色卡和本次目标。例如：

> 使用 `$sillytavern-cardplayer`，以娱乐模式游玩这张卡，目标是完成第一个主要事件，玩家类型选择好奇探索派。
